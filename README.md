# ideasos

Open source ideas for working with agents, at [ideasos.io](https://ideasos.io). Every idea is one markdown file with a licence, a verified date, and a twin an agent can read. Three kinds, one verb each:

| Kind | What it is | Its verb |
|---|---|---|
| **Guide** | Steps, with an `agent:` page in each | **Install** — one line puts a generated skill in `.claude/skills/`, and `/name` in Claude Code walks it |
| **How-to** | Steps or explanation, no agent page | **Send to your agent** — one line hands the file over as context |
| **Note** | A methodology, an opinion | **Open** |

No framework, no build for the site itself: `index.html`, `src/app.css`, `src/app.js`, and files. Hash routes (`#/ideas/doorman`), so any static server serves it.

## Layout

- `index.html` — the shell: masthead with the `ideas_os` mark, the menu, the theme control; the view; the status bar.
- `src/app.js` — the launcher. Renders the catalogue as a grid of cards, the prompt (search, or `install <idea>` / `send <idea>` / `open <idea>`), a post with your page and your agent's beside an index of the steps, the For agents and About pages. `window.App` is the test hook.
- `src/app.css` — the design: sea-green paper by day, deep teal at night, one coral LED for whatever is switched on; Bricolage Grotesque and Geist Mono. The agent's page is always the other theme.
- `index.json` — the catalogue. Per entry: `kind`, `slug`, `file`, `title`, `summary`, `parts`, `time`, `level`, `verified`, `status`, `agent`, `pdf`, and for guides `skill`.
- `ideas/*.md` — the ideas. Front matter, an introduction, `## N. Title` steps; `you:` opens your page and `agent:` your agent's, with `check:`, `confirm:` and `report:` lines inside it. A `wire:` line, left over from an earlier design, is ignored.
- `skills/<slug>/SKILL.md` — generated by `scripts/build_skills.py` from a guide's agent pages. Never edited by hand; the validator refuses a stale one.
- `llms.txt` — the index for agents.

## Run and test

```bash
python3 -m http.server 8790          # or the "ideasos" entry in .claude/launch.json
python3 scripts/build_skills.py       # after editing a guide
python3 scripts/validate.py           # must print: validation ok
python3 scripts/qa.py                 # headless Chrome, three viewports
```

## Adding an idea

1. Write `ideas/<slug>.md` with front matter (`title`, `kind`, `summary`, `by: ideasos`, `time`, `level`, `verified`, `parts`, `pdf`, optionally `repo`).
2. Add its entry to `index.json` with `status: live`. A guide gets `"skill": "skills/<slug>/SKILL.md"`.
3. `python3 scripts/build_skills.py`, add the file to `llms.txt`, then validate and QA.
